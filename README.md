## ❓ FAQ

<details>
<summary><b>How often does the playlist update?</b></summary>
<br/>
Every 1 hour automatically via GitHub Actions.
</details>

<details>
<summary><b>Which players are supported?</b></summary>
<br/>
VLC, TiviMate, OTT Navigator, IPTV Smarters, Kodi, Perfect Player, GSE Smart Pro — any player that supports M3U8.
</details>

<details>
<summary><b>Some channels don't work. Why?</b></summary>
<br/>
The playlist auto-filters dead links every hour, but streams can go down between updates. Wait for the next auto-update or re-add the playlist.
</details>

<details>
<summary><b>Is there an EPG (TV guide)?</b></summary>
<br/>
No. This playlist only contains live channels.
</details>

<details>
<summary><b>Can I fork and modify?</b></summary>
<br/>
Yes, free to use. Just give credit.
</details>
